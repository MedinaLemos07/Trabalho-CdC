DÚVIDAS FREQUENTES

Você ganha XP escaneando códigos de barras de embalagens recicláveis. Cada material vale um valor diferente: Papel +5 XP, Plástico +10 XP, Vidro +15 XP e Metal +20 XP. Missões concluídas também concedem XP bônus.

Cada código de barras pode ser escaneado no máximo 2 vezes por dia. Após isso, o sistema bloqueia novos scans daquele código até o dia seguinte.

Existem 5 ligas: Sucata, Reciclador, Guardião, Agente Eco e Lenda Verde. A cada semana, o top 3 de cada liga sobe e os últimos 3 descem. O XP semanal é zerado a cada segunda-feira.

Missões diárias resetam todo dia à meia-noite. Missões semanais têm metas maiores e recompensam mais XP. Complete ambas para maximizar seu progresso.

Parte dos competidores são agentes simulados para tornar o jogo mais dinâmico. Os nomes mudam a cada semana.

O navegador bloqueia o acesso à câmera em páginas abertas como arquivo local (file://). Use um servidor local como o Live Server do VSCode.

O streak conta quantos dias seguidos você reciclou pelo menos um item. Faça pelo menos um scan por dia.
