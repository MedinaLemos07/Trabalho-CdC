⚡ DÚVIDAS FREQUENTES

Você ganha XP escaneando códigos de barras de embalagens recicláveis. Cada material vale um valor diferente: Papel +5 XP, Plástico +10 XP, Vidro +15 XP e Metal +20 XP. Missões concluídas também concedem XP bônus.

Cada código de barras pode ser escaneado no máximo 2 vezes por dia. Após isso, o sistema bloqueia novos scans daquele código até o dia seguinte. Isso garante que o jogo seja justo para todos os agentes.

Cada nível exige mais XP que o anterior. Você começa como Recruta e pode chegar até Lenda. Conforme sobe de nível, seu título evolui automaticamente — acompanhe o progresso pela barra de XP no seu perfil.

Missões diárias resetam todo dia à meia-noite e oferecem objetivos rápidos como reciclar 3 itens ou um material específico. Missões semanais têm metas maiores e recompensam mais XP. Complete ambas para maximizar seu progresso.

Parte dos competidores no ranking são agentes simulados para tornar o jogo mais dinâmico enquanto a base de usuários cresce. Conforme mais agentes reais entram, os bots vão sendo substituídos. Usuários reais são identificados pelo sistema.

O navegador bloqueia o acesso à câmera em páginas abertas como arquivo local (file://). Para usar o scanner, o projeto precisa rodar em um servidor local. Use o comando python -m http.server 5500 no terminal e acesse via http://localhost:5500.

O streak conta quantos dias seguidos você reciclou pelo menos um item. Para não perder sua sequência, faça pelo menos um scan por dia. Se passar um dia sem reciclar, o contador zera e você começa do zero.
